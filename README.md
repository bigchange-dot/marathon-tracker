# 🏃 마라톤 트래커 — 2026-11-15 풀코스

풀코스 마라톤 완주를 위한 개인 훈련 트래커 PWA.
서버·DB 없이 정적 파일로만 동작하고, 기록은 브라우저(localStorage)에 저장된다.

## 사용법

- 폰 브라우저로 접속 → 메뉴에서 **"홈 화면에 추가"** 하면 앱처럼 사용
- **오늘**: D-day, 이번 주 진행률, 다음 훈련과 기록 입력 — 기록 폼에서 **가민 FIT 불러오기**(가민 커넥트 웹 → 활동 → ⚙ → 원본 내보내기 .zip)로 자동 입력
- **캘린더**: 14주 전체 스케줄, 계획 vs 실적, 놓친 훈련 표시
- **통계**: 주간 거리(계획 vs 실적)·페이스·통증 차트 + 기록 테이블
- **가이드**: 대회 전략, 페이스 가이드, 통증 신호등, 보강 운동, **JSON 백업/복원**

> 기록은 브라우저에만 저장되므로 **주 1회 JSON 내보내기**로 백업할 것.
> (2주 이상 백업이 없으면 앱이 리마인드 배너를 띄운다)

9~12차 축소 뒤에는 다른 세션만 줄어 롱런 비중이 56~72%까지 올라갔다. 하프 준비 때 무통증이던 사용자 방식(평일 3회 5~10km + 주말 롱런)을 기준으로 다시 짠다.

|---|---|---|---|

근거 (2026-10-21 확인):
1. Frandsen et al. 2025, BJSM — 가민 사용자 5,205명. 한 번 뛴 거리가 최근 30일 최장보다 10% 넘게 길면 과사용 부상 위험 증가(10~30%: +64%, 30~100%: +52%, 2배 이상: +128%). 주간 거리 증가율과는 관계가 확인되지 않음. 관찰 연구.
2. Jeukendrup — 1~2시간 30g/h, 2~3시간 60g/h, 2.5시간 넘으면 90g/h까지. 장은 훈련이 필요하다(30g/h 근처에서 몇 주에 걸쳐 올림).
3. Wen et al. 2019, J Sci Med Sport — HIIT 메타분석 53편. 지속주 대비 추가 효과는 긴 인터벌·4~12주 프로그램에서만.
4. Frontiers in Sports and Active Living 2024 — ITBS 보존 치료 체계적 문헌고찰. 연구 간 편차가 크고, 약한 엉덩이 근육이 원인인지는 논란.
5. Daniels — 롱런은 주간 거리의 25%(주 64km 이상)·30%(미만) 또는 150분 중 먼저 닿는 쪽. 11/4 20km(7'00" 기준 2:20)는 150분 안.

### 14차 검토 (2026-10-21) — 롱런은 대회 페이스 그대로, 평일에 템포

10/21 10km를 6'51" · 케이던스 176~181 · 보폭 80~84cm로 마쳤다. 대회 페이스는 6'50"~7'00"로 고정하고 롱런은 거리로 올린다.
"훈련 때 더 빠르게 뛰어봐야 대회 후반을 버틴다"는 사용자 문제 제기를 확인한 결과, 13차의 "인터벌 넣지 않음"은 근거를 너무 보수적으로 읽은 것이었다.

> 30km 이상을 한 번도 뛰지 않는 것은 의도된 설계다. 5시간대 완주자에게 30km는 3:45~4:00이고,
> 그 시점에서 추가 유산소 적응은 거의 없는 반면 회복 비용이 다음 주를 통째로 먹는다.

컷오프 **5시간 확정** — 한계 페이스 7'07"/km, 여유 5~12분. 구간별 통과 목표표는 앱 가이드 탭에.
